# News App

simple and interactive News Application built with HTML, CSS, and JavaScript that fetches the latest news headlines using the NewsAPI. Users can browse news articles by categories such as General, Entertainment, Health, Science, Sports, and Technology.

## Features
- Fetches real-time news using NewsAPI.
- Displays news with image, title, description, and "Read More" link.
- Category-based filtering (General, Sports, Technology, etc.).
- Responsive and clean UI.
- Fallback image when an article doesn’t have a cover.

## Tech Stack
-HTML – Structure
-CSS – Styling & layout
-JavaScript (Vanilla JS) – API integration & dynamic rendering
-NewsAPI – News data source

## 🔑 API Key Setup

This app uses the NewsAPI service.

Create a free account on NewsAPI.

Generate your API key.

Replace apiKey in the JavaScript file with your key:

const apiKey = "YOUR_API_KEY_HERE";
